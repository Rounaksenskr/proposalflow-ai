### Engagement Models
1. **Sprint-Based MVP:** $3,500 – $5,500 for a 4-to-6 week delivery cycle with bi-weekly milestone check-ins.
2. **Fixed-Scope Integration:** $1,500 – $3,000 for standalone API or microservice bridges (1-3 weeks).
3. **Hourly Baseline:** $85 – $110/hour for advisory, architectural review, or specialized AI/RAG prototyping.

### Minimum Engagement Rule
All client agreements mandate a minimum project threshold of $2,000. Projects requiring third-party API keys (e.g., Tavily, Stripe, LLM providers) are structured with client-provisioned credentials.
