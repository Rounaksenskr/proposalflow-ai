### Client Problem
The client managed a fleet of 45 cross-country delivery vans using disparate Google Sheets. Dispatchers suffered 30-minute delays in tracking vehicle availability and frequently double-booked cargo routes.

### Solution Delivered
Engineered a centralized real-time operations dashboard. The backend was built using FastAPI for REST endpoints and WebSockets for real-time status feeds, backed by PostgreSQL. The frontend was built with React and Tailwind CSS. Implemented strict role-based access control with JWT for drivers and dispatchers.

### Tangible Outcome
Eliminated dispatch double-bookings within the first two weeks of rollout and reduced daily operational reporting overhead by 35%.
